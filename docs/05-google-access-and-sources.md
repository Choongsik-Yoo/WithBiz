# Google 승인 사용자와 추가 출처 수집

## 접근 방식

Google OAuth만 로그인 화면에서 제공한다. Supabase가 발급한 OAuth 인증 방식(amr)과 서버의 Google identity 이메일 검증 상태를 확인한다. `private.allowed_users`의 활성 Gmail 주소만 데이터 API를 사용할 수 있다. 사용자 수정 가능 메타데이터는 권한 판단에 사용하지 않는다.

초기 관리자는 사용자가 지정한 `csyoo22@gmail.com`이다. 이 계정이 Google로 로그인하면 관리자 메뉴에서 Gmail 주소와 이름·소속을 입력하여 사용자를 등록할 수 있다. 등록된 사용자의 이용 차단/재허용도 가능하다. 관리자 자신의 차단은 방지한다. 작업은 비공개 감사 이력에 기록한다. 일반 사용자는 허용 목록을 읽거나 수정할 수 없다.

공고의 익명 접근을 제거했으며 기존 개인 데이터 정책에 승인 사용자 제한을 추가했다. SQL 권한 검사로 미등록 사용자·비밀번호 인증·메타데이터 관리자 위조·RPC 우회·차단 후 접근이 거부됨을 확인했다. 검증용 DB 계정/이메일 행은 트랜잭션 롤백으로 남기지 않았다.

Google API 권한은 openid/email/profile만 사용하며 Gmail 메일함 접근을 요청하지 않는다. WithBiz 전용 Google Cloud 프로젝트 `withbiz-ai`와 웹 클라이언트를 생성했다. OAuth 비밀키는 서버 제공자 설정과 무시되는 비공개 파일에만 저장한다.

## 실제 수집

추가 10개 출처의 공개 공고 수집기를 구현했다. 최신 목록에서 출처별 최대 30건을 조회한다. 전체 과거 공고 일괄 백필은 하지 않는다. 기존 중기부 API 수집과 함께 매일 한국 시간 06:00 GitHub Actions가 실행한다. 출처별 작업을 분리하여 한 기관의 실패가 다른 수집을 중단하지 않도록 한다.

| 출처 | 확인한 실제 수집 경로 | 첫 검증 수신 건수 |
|---|---|---:|
| NTIS | 공식 국가R&D 통합공고 목록·상세 | 10 |
| SMTECH | 공식 R&D 공고 목록·상세 | 10 |
| NIPA | 공식 사업공고 목록·상세 | 9 |
| KOCCA | 공식 지원공고 목록·상세 | 8 |
| 창조경제혁신센터 | 공식 공개 목록 JSON·상세 | 10 |
| 지역 테크노파크 | 진흥회 통합 사업공고 목록·지역 TP 상세 | 6 |
| TIPS | 공식 공고/지침 목록·공개 상세 JSON | 10 |
| 한국벤처투자 | 공식 투자사업공지 목록·상세 | 10 |
| 소상공인24 | 소진공 공식 홈페이지에 게시된 소상공인24 연계 목록 | 10 |
| 소상공인시장진흥공단 | 동일 공식 홈페이지 연계 목록, 출처 이력 통합 | 10 |

중복 통합 후 추가 고유 공고 82건, 전체 1,502건을 저장했다. 수신 수와 고유 공고 수는 다르다. 본문 조회에 실패하거나 이미지 위주인 공고는 목록 제목·원문을 저장하고 원문 확인이 필요함을 표시한다. 소상공인24의 상세 API는 현재 서버 오류 응답으로 직접 사용하지 않고 소진공 공식 공개 연계 목록을 사용한다. 마감일은 D-day로 역산하거나 추정하지 않는다. HTTPS 원문 URL만 저장하며 페이지에서 임의 스크립트를 실행하지 않는다.

MSS·기업마당 중복 원천과 소상공인24·소진공의 동일 공고를 통합한다. 추가 출처 간 완전히 같은 제목·기관·마감일도 보수적으로 통합하고 출처별 외부 ID를 보존한다. 기관별 페이지 구조 변경·시간 초과는 수집 오류 이력으로 남기고 기존 공고를 삭제하지 않는다.

K-Startup은 기존 인증 연결 보류 상태다. AI 분석과 실제 알림 발송은 이번 변경 범위에 포함하지 않는다.

## 검증

- 기존/추가 수집기 테스트 13개 통과
- TypeScript 전체 검사와 정적 프로덕션 빌드 통과
- 실제 추가 10개 출처의 수집·저장 및 중복 이력 확인
- 승인 사용자 접근/비승인 차단/비밀번호 차단/역할 위조 차단/즉시 이용 차단 SQL 검증 통과
