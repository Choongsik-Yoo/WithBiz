# WithBiz AI 아키텍처와 화면 설계 검토안

작성일: 2026-10-27 · STEP 3 · 상태: 설계 작성 완료, 구현 전 검토

## 이번 단계의 결정

사용자 지시에 따라 외부 API 연결은 후속 작업으로 보류하고 설계를 진행했다. 기본 구성은 Next.js 웹앱과 Supabase, 별도 실행되는 수집·매칭 작업, Claude와 임베딩·메일 어댑터다. WithBid AI에서 읽은 실제 디자인 토큰을 계승한다. 연결되지 않은 서비스는 개발용 샘플과 명확히 구분한다.

이 문서는 앱 구현·DB 생성·외부 배포 완료 보고가 아니다. 마스터 프롬프트의 STEP 3 설계 승인 대상으로, 검토 후 STEP 4 구현을 진행한다. 사용자에게 API를 다시 연결해 달라는 요구로 설계를 중단하지 않는다.

## 남은 후속 연결

기업마당·중기부는 인증된 표본 조회를 확인했다. K-Startup 인증, 기업마당 첨부 실패, Supabase 프로젝트, Claude·임베딩·Resend 계정과 발신 도메인, 지도 경계 데이터의 출처·이용 조건은 후속 연결 목록이다. API 인증키는 이미 로컬 비밀 파일에 있으며 재전달할 필요가 없다. 저장된 키를 화면·샘플·문서에 포함하지 않는다.

임베딩 공급자는 Voyage 계열 2개 후보를 비교하는 설계로 두며 품질 검증 전 특정 모델의 한국어 추천 품질을 보장하지 않는다. 모델·차원은 공급자 설정과 별도 마이그레이션으로 교체할 수 있게 한다.

## 구현 단계 순서

STEP 4에서는 모노레포와 검증 가능한 샘플 저장소부터 만들고, 수집 인터페이스·정규화 → 공고 목록·상세 → 대시보드 → 회원·기업 프로필 → 매칭 → 알림 → 관리자 순으로 진행한다. 외부 서비스가 없는 상태에서는 시연 범위와 실제 연결 범위를 실행 안내에 명시한다.
