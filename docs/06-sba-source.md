# SBA 지원사업 수집 (2026-10-29)

- 공식 목록: https://www.sba.seoul.kr/Pages/BusinessApply/Posting.aspx
- 출처 코드 `sba`, 이름 `SBA 서울경제진흥원`, 우선순위 3(서울·기업지원).
- ASP.NET 공식 목록 첫 페이지의 최신 10개 공고를 수집한다. 전체 과거 공고 백필은 하지 않는다.
- 목록의 고유 GUID로 안정적인 상세 URL과 `sba:GUID` 키를 구성한다. 중첩 테이블의 행사기간 대신 명시적인 접수 시작일·종료일 필드를 읽는다.
- 상세 `#new_ntxt_description` 본문과 공식 이미지 대체 텍스트를 저장한다. 이미지·문서만 있고 읽을 본문이 없으면 원문 확인 필요를 표시한다. 첨부문서는 다운로드·변환하지 않고 공식 첨부 링크를 저장한다.
- 기관이 서울에 있다는 이유만으로 모든 공고의 신청 가능 지역을 서울로 확정하지 않는다. 최종 자격과 마감 시각은 원문을 확인한다.
- 매일 한국 시간 06:00 기존 수집 워크플로에 포함한다. 관리자 재수집 요청은 기존 활성 출처 등록 방식으로 지원한다.

## 검증 결과

- 실제 최초 수집: 10건 수신, 10건 신규 저장.
- 즉시 재수집: 10건 수신, 신규 0건, 변경 0건. 고유 ID 기준 중복 방지 확인.
- 저장한 10건 모두 본문 100자 이상 및 공식 첨부 링크 확인.
- SBA 목록·본문·첨부·이미지 대체 텍스트 검증 3개 포함 전체 테스트 16개 통과. TypeScript 검사 통과.
- 증거: `docs/evidence/sba-collection.json`.
